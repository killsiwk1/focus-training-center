# 本地版本构建

通用版由根目录的 start.py、dist、LICENSE 和 NOTICE 组成。按原目录层级压缩，解压后执行 python3 start.py。

Windows 在 platforms/windows 内使用 Go 1.26，关闭 CGO，设置 GOOS=windows，分别以 GOARCH=amd64、arm64、386 编译 main.go。三个目标文件依次命名为 runtime/focus-x64.exe、runtime/focus-arm64.exe 和 runtime/focus-x86.exe。将 dist 的内容复制到同级 site 目录，顶层放置启动 CMD，同时保留 Go 版权文件。

macOS 使用 Xcode 命令行工具。创建“专注力训练中心.app/Contents”，复制 platforms/macos/Info.plist，用 clang -fobjc-arc -arch arm64 -arch x86_64 -mmacosx-version-min=11.0 -framework Cocoa launcher.m -o FocusCenter 编译，在 Contents/MacOS 下放置 FocusCenter，在 Contents/Resources/site 下放置 dist 内容。对应用签名并用 hdiutil create 制作映像。以本地签名构建的产物没有 Apple 公证。

Android 使用 JDK 17、Android 平台 35 和 Build Tools 35。复制 dist 为 assets，在 assets 目录执行 patch -p1 < /实际路径/platforms/android/assets.patch，启用系统文件选择器与离线状态。拷贝 icon-192.png 为 res/drawable-nodpi/icon.png。用 aapt2 compile/link 处理资源和清单、javac 编译 Main.java、d8 转换为 classes.dex，加入 APK 后运行 zipalign，再使用自己的密钥通过 apksigner 签名。官方更新需要同一签名身份。分支自行签名的版本不能覆盖原签名版本。
