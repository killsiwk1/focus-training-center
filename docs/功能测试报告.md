# 专注力训练中心 · 功能验收报告

测试日期为 2026 年 11 月 20 日。验收基于本机运行的交付应用，使用独立的临时浏览器配置。所有用于核对成绩的数据都来自测试流程中的实际界面作答。交付网站首次打开时成绩库为空。

## 验收结果

| 验证项 | 实际操作与结果 |
| --- | --- |
| 出题规则 | Node.js 运行 7 组规则测试，全部通过。五档难度各进行 500 轮抽样，核对方格数字的完整性和唯一性、中文颜色及冲突标记、数值唯一解、方向规则与切换状态、视觉选项唯一性和题库变化。另核对记忆长度边界及同条件成绩比较。 |
| 六项完整训练 | 通过浏览器逐项完成 6 个项目 × 5 档难度 × 2 种模式，共 60 种组合。每场送入正确与错误作答，经页面结算后读取成绩库，核对项目、难度、模式、正误次数、正确率、作答条数和首次最佳。记忆训练覆盖数字、颜色、图形。 |
| 正常计时与限时 | 舒尔特方格验证完整找完与 30 秒到期两条路径。到期时保存 30 秒及已找到的格数。验证暂停、说明、重新开始和放弃本项，未结算退出不会产生额外历史成绩。 |
| 字色、数值、方向、图形作答 | 根据题面实际墨色、数值、规则或图形内容选择答案。用键盘数字键和触控按钮进行作答。固定正向、固定反向和切换规则均经界面验证。 |
| 每日训练 | 从六项改为两项，调整顺序与难度，将每项改为 1 分钟，先完成限时字色训练，再完成方格。整组结果记录两项，当日计划显示 2 / 2。 |
| 随机挑战 | 要求随机抽取 6 项，连续作答并逐项结算，最终整组报告展示六条记录和合计用时。 |
| 报告和历史 | 切换最近 7 天、最近 30 天、全部历史、挑战模式及难度；核查六个项目的趋势图。按项目和模式筛选历史，打开单场成绩及逐次作答用时。 |
| 持久化 | 保存 69 条测试记录，关闭测试浏览器进程，使用同一临时配置重新打开。69 条记录及修改后的默认难度均保留。 |
| 导出和恢复 | 下载并读取 CSV 成绩表和 JSON 备份。同一备份再次恢复新增 0 条；无效备份被拒绝。将含六项离线作答的备份导入另一份空白浏览器配置，新增六条，偏好与数据在刷新后保留。 |
| 离线训练 | 等待资源缓存就绪，在浏览器网络层断网，重新加载应用，完成训练并保存。另在触控浏览器环境中全程离线，分别完成六项练习并结算，恢复联网后数据可继续使用。 |
| 安装条件 | 浏览器读取应用清单、中文名称、独立窗口设置和两种尺寸图标，安装条件检查返回零项错误。资源缓存清单与运行目录中的全部必要资源匹配。 |
| 响应式布局 | 在 320、375、390、768、1024 和 1440 像素宽度检查首页、每日计划、随机挑战、历史、报告、设置与记忆配置页，均无页面横向溢出。另验证手机抽屉导航及 7×7 方格完整操作，检查桌面和手机截图。 |
| 苹果渲染引擎 | 在 macOS 原生 WebKit 的 390 像素宽独立窗口中完成全部六项练习，验证结算、无横向溢出和六条历史记录。 |

Chromium 主流程合计 17 组检查通过，执行过程中未捕获到页面脚本异常。离线触控、安装条件和跨浏览器配置恢复另有独立测试脚本。

## 已修复并回归的问题

连续修改每日计划时，较早的异步保存可能重绘表单，覆盖刚输入的分钟数。现在编辑立即更新当前计划，保存完成时保留正在编辑的控件。回归用例核对实际开始时的倒计时，并验证 1 分钟到期后的结算与下一项衔接。

## 环境及边界

- 在 macOS 13.7.8 上使用 Chromium 系浏览器 151.0.7683.170，以及系统 WebKit。浏览器矩阵、断网和触屏条件由自动化测试控制。
- 时限和记忆序列的批量测试使用可控浏览器时钟推进，不同答题速度的数据均只用于软件验收。
- Windows、安卓手机和 iPhone 的物理设备、操作系统桌面安装对话框和长期在线可用性均未做实机或持续观察。苹果 WebKit 窄屏测试覆盖引擎和布局，手机桌面安装手势仍需在实际设备上验证。
- 浏览器功能测试针对本地同源版本，正式托管发布状态单独确认。复测命令、首次离线准备及备份恢复步骤见 README。
