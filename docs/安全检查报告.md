# 公开发布前检查

## 范围与结果

从训练项目的两个本地历史提交读取 33 个不同的 Git 文件对象，检查常见 GitHub 令牌、云服务访问密钥、API 密钥、私钥块和带凭据的连接地址特征，未发现命中。公开目录从明确选定的源文件创建，全新建立 Git 历史，旧提交作者信息、远程仓库配置以及专属托管项目编号均未复制。

Android 构建工作区含发布用签名私钥及其口令文件；二者保留在原工作区，不在公开目录或 APK 内。APK 签名的公开证书可用于验证安装包。检查公开目录文件名、文件内容和 ZIP、APK 内部成员。未发现上述密钥特征、环境变量文件、本机成绩数据库或成绩备份。特征扫描并非绝对安全保证。

## 资源与依赖

六个训练模块及运行页面与原项目逐文件一致。界面图标、图形、首页装饰及应用图标为本项目生成；使用设备已有字体。网页运行无需远程字体、图床或第三方脚本。平台 SDK、JDK、编译器、浏览器程序及工具缓存不进入源码仓库。Windows 包含 Go 运行时，相应版权许可已保留。Playwright 仅用于开发验收，使用者自行安装。

## 数据边界

成绩由本机 IndexedDB 保存，备份和恢复由使用者发起。桌面启动程序仅监听回环地址。第三方浏览器扩展、用户自行分享的备份文件和平台签名私钥不在本项目发布范围内。
