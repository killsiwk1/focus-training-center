六项简体中文练习，用于记录个人的练习表现。成绩用于观察同条件下的变化，不提供医学诊断。

## 软件下载与安装

**请优先下载本地版本使用。** 打开 [Releases 下载页](../../releases)，选择 v1.0.0，展开 Assets（附件）。

| 下载文件 | 适用设备 | 安装与启动 |
| --- | --- | --- |
| focus-macos-1.0.0.dmg | macOS 11 及以上，Intel 和 Apple 芯片 | 双击映像，将应用拖到「应用程序」，打开后使用默认浏览器训练。从菜单栏「专注训练」退出。 |

下载后可用 SHA256SUMS.txt 核对完整性。Windows 使用 PowerShell 的 `Get-FileHash 文件名`，macOS 使用 `shasum -a 256 文件名`。Windows 和 Android 包已经过构建与结构验证，尚未在对应系统实机验收。Mac 版采用本地签名，尚未经 Apple 公证。如遇系统阻止，可选择通用离线包。



## 从源码启动

安装 Python 3，在项目目录执行以下命令。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Windows 可使用 `py -3` 替换 `python3`。在同一台电脑的浏览器打开 `http://127.0.0.1:8765/`，使用期间保持服务运行。请固定使用同一浏览器、地址和端口，以持续访问同一份成绩库。应用使用原生 JavaScript 模块和 CSS，部署时直接使用 dist 目录，无需运行构建工具。

## 开始训练

- **独立训练**　从首页进入项目，选择模式与难度。练习可以主动结算、重开和查看说明。挑战按固定题量或时限自动结算。
- **每日训练**　在“每日训练”中勾选项目，以“上移”和“下移”安排顺序，设定每项 1 至 30 分钟的上限。计划自动保存。到时结算，至少实际作答一次才计入当天完成。舒尔特方格全部找完可提前结算。每日计划按设备本地日期更新。
- **随机挑战**　选择 1 至 6 个项目，系统随机抽取并打乱顺序。单项完成后可查看成绩，再继续下一项。队列保存后可以从每日训练或随机挑战页面继续，未结算的单项从头开始。
- **键盘**　Tab 在控件间移动，空格或回车激活按钮。数字键 1 至 9 对应作答选项的显示顺序。数值比较也支持左右方向键，方向任务支持对应的方向键。方格支持 Tab 选择后按空格或回车。
- **暂停**　暂停、查看训练说明或切到后台会遮住题面，暂停计时。返回后主动继续。未保存的练习在退出前会要求确认。

## 题目与成绩

| 项目 | 任务与难度 | 主要成绩 |
| --- | --- | --- |
| 舒尔特方格 | 依次寻找数字。五级分别为 4×4、5×5、5×5、6×6、7×7，中级起隐藏已找到标记。独立挑战限时 30 秒。 | 完成用时，未完成时显示已找到格数，同时记录误点 |
| 字色干扰 | 只判断字的实际颜色。中文颜色词和墨色可一致或冲突，冲突概率随等级及轮次上升。 | 正确率，同率比较平均反应时间 |
| 数值干扰 | 选择实际数值较大的数字。提高等级会扩大数值范围，增加字号差异与冲突概率。 | 正确率与平均反应时间 |
| 序列记忆 | 依次记忆数字、颜色或图形。可设起始长度、显示时间和间隔。整组复现正确加一位，错误减一位，范围 2 至 14 位。 | 最高正确长度、整组正确率、复现作答用时 |
| 反向线索任务 | 按当题指令选择正向或反向。支持固定规则及随机切换，中级起增加上下方向。 | 正确率、平均反应时间、切换题错误数 |
| 视觉完型测试 | 残缺轮廓、遮挡图形、循环图案补全。轮廓与中心符号组合生成题目，较难等级使用相似选项。 | 正确率与平均答题时间 |

个人最佳在同一项目、模式、难度与计时等设置内比较。首页展示最近一场及其同组最佳。报告可切换 7 天、30 天和全部历史，切换模式、难度和各项目设置。折线的横向顺序为训练先后，舒尔特完成用时越短越好，其余项目的正确率或记忆长度越高越好。舒尔特的时间均值只计完整找完的一场。所有记录可在历史页逐题查看。

## 数据备份与恢复

1. 在“设置”下载完整备份。JSON 文件包含成绩、逐题记录、计划、队列和训练偏好。
2. 在目标设备或新浏览器打开网站，进入“设置 → 恢复备份”。确认后按记录编号合并，重复导入会去重，个人最佳按时间重新计算。
3. 如需在表格软件中分析，选择“导出成绩表”。CSV 包含各次训练的指标，完整迁移使用 JSON 备份。
4. 清理浏览器网站数据、更换域名或更换设备前请先备份。训练数据不会上传，也没有账号同步功能。设备时钟和本地日期用于划分每日记录。

## 每项练习的重点

舒尔特方格练习视觉搜索，字色干扰练习选择性注意，数值干扰练习过滤字号干扰。序列记忆练习短时记忆和顺序复现，反向线索练习抑制控制和规则切换，视觉完型练习图形识别和局部线索整合。

## 更新与常见问题

- **如何保留成绩？** 更新前在设置中导出完整备份。桌面版退出服务后替换应用或解压新版，继续使用原浏览器及原地址。Android 用相同签名的新版覆盖安装；卸载前先备份。
- **双击 HTML 后显示空白？** 网站使用 JavaScript 模块，请从启动程序或离线包脚本进入。
- **提示端口被占用？** 先退出之前运行的训练中心，再打开新版。同一时间只运行一个本机版本。
- **换设备后没有历史？** 在原设备导出 JSON 备份，在新设备的设置中恢复。CSV 用于分析，不能恢复完整训练状态。
